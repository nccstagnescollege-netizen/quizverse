# QUIZVERSE API Conventions & Standards

## 1. Base URL & Versioning

All API endpoints reside under versioned paths:
```
https://api.quizverse.domain/api/v1/*
```
Breaking changes will increment the major version path (`/api/v2/*`).

---

## 2. Standardized Response Format

All responses follow a predictable JSON contract defined in `@quizverse/shared`.

### 2.1 Success Response (`200 OK`, `201 Created`)
```json
{
  "success": true,
  "data": {
    "status": "healthy",
    "uptimeSeconds": 1420,
    "service": "quizverse-api",
    "version": "1.0.0",
    "environment": "production"
  },
  "meta": {
    "requestId": "9c1b3f20-9bf7-49f3-8b71-12c82305881a",
    "timestamp": "2024-11-17T11:45:00.000Z",
    "version": "v1"
  }
}
```

### 2.2 Error Response (`400`, `401`, `403`, `404`, `422`, `500`)
```json
{
  "success": false,
  "error": {
    "code": "VALIDATION_FAILED",
    "message": "Input validation failed",
    "details": [
      {
        "code": "VALIDATION_ERROR",
        "message": "Please enter a valid email address",
        "path": ["email"]
      }
    ]
  },
  "meta": {
    "requestId": "9c1b3f20-9bf7-49f3-8b71-12c82305881a",
    "timestamp": "2024-11-17T11:45:00.000Z",
    "version": "v1"
  }
}
```

## 3. Standard HTTP Status Codes

| Code | Meaning | Use Case |
| :--- | :--- | :--- |
| **200 OK** | Success | Read queries, successful updates |
| **201 Created** | Created | Resource generated (quiz, question, attempt) |
| **400 Bad Request** | Malformed | Invalid payload or missing mandatory header |
| **401 Unauthorized** | Unauthenticated | Missing or expired JWT token |
| **403 Forbidden** | Access Denied | Authenticated user lacks required role (e.g. Student accessing Admin) |
| **404 Not Found** | Missing Resource | Endpoint or entity ID does not exist |
| **422 Unprocessable** | Validation Failure | Zod schema validation failed on request input |
| **500 Server Error** | Internal Failure | Uncaught exception masked behind generic error response |

---

## 4. Mandatory Headers

- `X-Request-Id`: Automatically generated by the backend if not supplied by the client. Always returned in response headers and inside `meta.requestId`.
- `Content-Type`: `application/json` for mutation endpoints.
